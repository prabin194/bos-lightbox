How to Use

Install via npm or use directly from a CDN.

# Install
$ npm install document-preview

Then import and use in your project:

import 'document-preview';

// Define your items
const items = [
  { url: 'image.jpg', type: 'image', name: 'Photo' },
  { url: 'doc.pdf',   type: 'pdf',   name: 'Document' },
  { url: 'file.zip',  type: 'other', name: 'Archive' },
];

// Get the element
const preview = document.querySelector('document-preview');

// Open at a specific index
preview.items = items;
preview.initialIndex = 0;
preview.open = true;

// Listen for events
preview.addEventListener('close', () => console.log('closed'));
preview.addEventListener('download', (e) => console.log(e.detail));

For full-page dialog-like preview, set display-mode attribute:


<document-preview id="preview" display-mode="inline"></document-preview>

<script>
  preview.items = items;
  preview.open = true; // Opens full-page like a dialog box
</script>

CDN (no build step)

Use directly in any HTML page via a CDN.

<!-- After publishing to npm -->
<script type="module">
  import 'https://unpkg.com/document-preview@latest/dist/document-preview.js';
</script>

<!-- Or from a local build -->
<script type="module">
  import './dist/document-preview.js';
</script>

<document-preview id="preview"></document-preview>

API Reference

Properties, attributes, and events supported by the component.

Name Type Description
items property Array of {url, type, name} objects to preview
open attribute Boolean — shows/hides the lightbox
initial-index attribute Number — index of the item to show first
loop property Boolean — wrap navigation from last to first (default false)
close-on-overlay attribute Boolean — close when clicking the overlay background (default true)
close-on-escape attribute Boolean — close when pressing Escape (default true)
display-mode attribute String — "modal" for overlay with focus trap, "inline" for full-page dialog-like display (default "modal")
downloadable property Boolean — show download button (default true)
open() / openAt(index) method Open the lightbox, optionally at a specific index
next() / prev() method Programmatically navigate between items
goTo(index) method Jump to a specific item by index
close event Dispatched when the lightbox is closed
open event Dispatched when the lightbox opens
item-change event Dispatched on navigation. e.detail contains {previousIndex, currentIndex, item}
download event Dispatched when download is clicked. e.detail.item contains the item
error event Dispatched when an image/PDF fails to load. e.detail contains {item, error}
