Changelogs

All releases, improvements, and fixes for bos-lightbox.

  1. v0.1.0Latest
    Initial release — React-based lightbox
    • ✨Converted from Lit web component to pure React with forwardRef and useImperativeHandle API.
    • 🔧Native <dialog> element for modal mode with built-in focus trapping and Escape handling.
    • 🖼️Image viewing with loading spinner, fade-in transition, and zoom controls (in/out/reset).
    • 📄PDF preview via iframe with error handling for failed loads.
    • 🔤Fallback UI for unsupported file types with download option.
    • ⌨️Keyboard navigation (Arrow Left/Right) and touch swipe support.
    • 🔄Circular navigation (loop mode) and configurable close behaviors.
    • 📥Built-in download functionality with fetch+blob fallback.
    • 📦Zero runtime dependencies — only React as peer dep. ESM + CJS builds.
