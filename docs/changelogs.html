  1. v0.1.0Latest
    Initial release
    • ✨React component with forwardRef and imperative API
    • 🔧Native <dialog> modal with focus trapping
    • 🖼️Image viewing with zoom, drag-to-pan, fade-in
    • 📄PDF preview via iframe with error handling
    • 🎬Video support with native controls and autoplay
    • ⌨️Keyboard nav, touch swipe, circular loop mode
    • 🔁Slideshow auto-play with configurable interval
    • 🖼️Bottom thumbnail strip for visual navigation
    • 🎭Fade animations and custom renderItem prop
    • 📥Download with fetch+blob fallback
    • 📦Zero runtime deps. ESM + CJS builds. TypeScript types.
