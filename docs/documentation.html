Documentation

API reference and usage guide for bos-lightbox — a React component for previewing images, PDFs, videos, and other files.

Installation

$ npm install bos-lightbox

Requires React 16.8+. No other runtime dependencies.

Basic usage

BosLightbox is a controlled component — you manage the open state yourself and pass onClose to handle closing.

import { useState } from "react"
import { BosLightbox } from "bos-lightbox"

function Gallery() {
  const [open, setOpen] = useState(false)
  const items = [
    { url: "/photos/sunset.jpg", type: "image", name: "Sunset" },
    { url: "/photos/ocean.jpg",  type: "image", name: "Ocean view" },
  ]

  return (
    <>
      <button onClick={() => setOpen(true)}>
        Open gallery
      </button>
      <BosLightbox
        items={items}
        open={open}
        initialIndex={0}
        onClose={() => setOpen(false)},
      />
    </>
  )
}

Type definitions

PreviewItem

Each item in the lightbox follows this shape:

{
  url: string // path or URL to the file
  type: "image" | "pdf" | "video" | "other"
  name: string // shown in the header
}
  • "image" — Renders with <img>, includes zoom and drag-to-pan.
  • "pdf" — Renders in an <iframe>. Falls back to download on error.
  • "video" — Native <video> with controls and autoplay.
  • "other" — Shows a file icon and name. Encourages download.

BosLightboxRef

Methods exposed via the ref prop:

{
  openAt(index): void
  goTo(index): void
  next(): void
  prev(): void
  close(): void
  getCurrentIndex(): number
  getCurrentItem(): PreviewItem | undefined
  toggleSlideshow(): void
  isSlideshowActive(): boolean
}

Ref / imperative methods

Use a ref to control the lightbox from a parent component.

import { useRef } from "react"
import { BosLightbox, type BosLightboxRef } from "bos-lightbox"

const ref = useRef<BosLightboxRef>(null)
<BosLightbox ref={ref} items={items} open={open} onClose={() => setOpen(false)} />

Event callbacks

The component fires several callbacks during its lifecycle.

<BosLightbox
  items={items}
  open={open}
  onClose={() => setOpen(false)}
  onOpen={() => console.log("opened")}
  onItemChange={({ currentIndex, item }) => {
    console.log("Now viewing:", item.name)
  }}
  onDownload={({ item }) => {
    console.log("Downloaded:", item.name)
  }}
  onError={({ item, error }) => {
    console.error("Error loading", item.name, error)
  }}
/>

Display modes

Modal mode (default)

Uses the native <dialog> element with showModal():

  • Automatic focus trapping
  • Built-in Escape key handling
  • ::backdrop with blur effect
  • Top-layer rendering (no z-index issues)
<BosLightbox
  items={items}
  open={open}
  displayMode={"modal"}
  onClose={() => setOpen(false)}
/>

Inline mode

Renders as a fixed-position overlay. Header navigation and dot indicators replace floating arrows.

<BosLightbox
  items={items}
  open={open}
  displayMode={"inline"}
  onClose={() => setOpen(false)},
/>
Note: In inline mode, nav buttons live in the header bar. Use style and className for custom positioning.

Slideshow mode

Enable auto-play with the slideshow prop. The lightbox advances at a regular interval and pauses on manual navigation.

<BosLightbox
  items={items}
  open={open}
  slideshow
  slideshowInterval={5000}
  loop
  onClose={() => setOpen(false)}
/>
Note: Without loop, the slideshow stops at the last item.

Thumbnail strip

Add a bottom row of thumbnails for visual navigation between items.

<BosLightbox
  items={items}
  open={open}
  thumbnails
  onClose={() => setOpen(false)}
/>
Note: Non-image types show a type icon in the thumbnail.

Custom rendering

Use renderItem to override how items are rendered.

<BosLightbox
  items={items}
  open={open}
  onClose={() => setOpen(false)}
  renderItem={(item) => {
    if (item.type === "image") {
      return <CustomImageViewer url={item.url} />
    }
    return null
  }}
/>

Zoom controls

Available for "image" items. Controls appear in the bottom-right corner.

ControlBehavior
Zoom in (+)+0.25x (max 5×)
Zoom out (−)−0.25x (min 0.25×)
ResetBack to 1× (only visible when zoomed)

When zoomed in, click and drag to pan.

Download

The download button runs this flow:

  1. Fires onDownload
  2. Tries fetch with mode: "cors" to get a Blob
  3. Creates a download link via URL.createObjectURL
  4. Falls back to <a download> if fetch fails

Set downloadable={false} to hide the button.

Touch & swipe

A swipe is registered when:

  • Horizontal distance exceeds 50px
  • Horizontal distance exceeds vertical distance

Swipe right → previous. Swipe left → next.

Examples

Image gallery with zoom

import { useState } from "react"
import { BosLightbox } from "bos-lightbox"

const images = [
  { url: "https://picsum.photos/id/10/800/600", type: "image", name: "Forest path" },
  { url: "https://picsum.photos/id/20/800/600", type: "image", name: "Mountain lake" },
]

function Gallery() {
  const [open, setOpen] = useState(false)
  return (
    <>
      <button onClick={() => setOpen(true)}>View gallery</button>
      <BosLightbox
        items={images}
        open={open}
        loop
        onClose={() => setOpen(false)}
      />
    </>
  )
}

Mixed content (images + PDFs + video)

const items = [
  { url: "/slides/intro.png",    type: "image", name: "Slide 1" },
  { url: "/slides/report.pdf",   type: "pdf",    name: "Report" },
  { url: "/slides/demo.mp4",     type: "video",  name: "Demo" },
]

<BosLightbox
  items={items}

  initialIndex={1}

/>

Imperative control with ref

import { useRef } from "react"
import { BosLightbox, type BosLightboxRef } from "bos-lightbox"

function ControlledPreview() {
  const ref = useRef<BosLightboxRef>(null)
  const [open, setOpen] = useState(false)
  return (
    <>
      <button onClick={() => ref.current?.openAt(0)}>Open first</button>
      <BosLightbox
        ref={ref}
        items={items}
        open={open}
        onClose={() => setOpen(false)}
      />
    </>
  )
}
