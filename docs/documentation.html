Documentation

Complete API reference and usage guide for bos-lightbox — a lightweight, accessible React component for previewing images, PDFs, videos, and documents.

Installation

$ npm install bos-lightbox

Requires React 16.8+ (Hooks-compatible). No other runtime dependencies.

Basic usage

The BosLightbox component is controlled — you manage the open state via a parent React state variable, and pass onClose to update it.

import { useState } from "react"
import { BosLightbox } from "bos-lightbox"

function Gallery() {
  const [open, setOpen] = useState(false)
  const items = [
    { url: "/photos/sunset.jpg", type: "image", name: "Sunset" },
    { url: "/photos/ocean.jpg",  type: "image", name: "Ocean view" },
  ]

  return (
    <>
      <button onClick={() => setOpen(true)}>
        Open gallery
      </button>
      <BosLightbox
        items={items}
        open={open}
        initialIndex={0}
        onClose={() => setOpen(false)}
      />
    </>
  )
}

Type definitions

PreviewItem

The core data type describing each item in the lightbox.

// Represents a single previewable item
{
  url: string // URL or path to the file
  type: "image" | "pdf" | "video" | "other" // Determines the renderer
  name: string // Display name / filename
}

Item types:

  • "image" — Renders with native <img>, loading spinner, zoom, and drag-to-pan.
  • "pdf" — Renders in an <iframe>. Shows error fallback on failure.
  • "video" — Renders a native <video> element with controls and autoplay.
  • "other" — Shows a generic file icon with name. Encourages download.

BosLightboxRef

Methods available via the ref prop for imperative control.

// Imperative control methods
{
  openAt(index: number): void
  goTo(index: number): void
  next(): void
  prev(): void
  close(): void
  getCurrentIndex(): number
  getCurrentItem(): PreviewItem | undefined
  toggleSlideshow(): void
  isSlideshowActive(): boolean
}

Ref / imperative methods

Use a ref to programmatically control the lightbox from a parent component.

import { useRef } from "react"
import { BosLightbox, type BosLightboxRef } from "bos-lightbox"

const ref = useRef<BosLightboxRef>(null)
<BosLightbox ref={ref} items={items} open={open} onClose={() => setOpen(false)} />

// Usage
ref.current?.openAt(2)
ref.current?.next()
ref.current?.close()
MethodReturnsDescription
openAt(index)voidOpens the lightbox at the specified item index. Clamps to bounds.
goTo(index)voidNavigate to a specific item index.
next()voidNavigate to the next item. Respects loop setting.
prev()voidNavigate to the previous item. Respects loop setting.
close()voidTriggers onClose to close the lightbox.
getCurrentIndex()numberReturns the index of the currently displayed item.
getCurrentItem()PreviewItem | undefinedReturns the currently displayed item object.
toggleSlideshow()voidToggles slideshow play/pause.
isSlideshowActive()booleanReturns whether slideshow is currently active.

Event callbacks

The component fires several callbacks during its lifecycle. Use them for analytics, logging, or side effects.

<BosLightbox
  items={items}
  open={open}
  onClose={() => setOpen(false)}
  onOpen={() => console.log("opened")}
  onItemChange={({ currentIndex, item }) => {
    console.log("Now viewing:", item.name)
  }}
  onDownload={({ item }) => {
    console.log("Downloaded:", item.name)
  }}
  onError={({ item, error }) => {
    console.error("Error loading", item.name, error)
  }}
/>

Display modes

Modal mode (default)

Uses the native <dialog> element with showModal(). This provides:

  • Automatic focus trapping
  • Built-in Escape key handling
  • ::backdrop pseudo-element with blur effect
  • Proper stacking context (top-layer rendering)
<BosLightbox
  items={items}
  open={open}
  displayMode={"modal"}
  onClose={() => setOpen(false)}
/>

Inline mode

Renders the lightbox as a fixed-position overlay within the page. Includes header navigation and dot indicators. Useful for embedded galleries or custom layouts.

<BosLightbox
  items={items}
  open={open}
  displayMode={"inline"}
  onClose={() => setOpen(false)}
/>
Tip: In inline mode, navigation buttons appear in the header bar rather than as floating side arrows. Use style and className for custom positioning.

Slideshow mode

Enable auto-playing slideshow with the slideshow prop. The lightbox auto-advances through items at the configured interval and pauses on manual navigation.

<BosLightbox
  items={items}
  open={open}
  slideshow
  slideshowInterval={5000}
  loop
  onClose={() => setOpen(false)}
/>
Tip: When loop is false, the slideshow stops at the last item. Enable loop for continuous playback.

Thumbnail strip

Show a bottom row of thumbnails for quick visual navigation between items.

<BosLightbox
  items={items}
  open={open}
  thumbnails
  onClose={() => setOpen(false)}
/>
Tip: For PDF, video, and other types, the thumbnail shows a type icon instead of an image preview.

Custom rendering

Use the renderItem prop to take full control over how each item is rendered.

<BosLightbox
  items={items}
  open={open}
  onClose={() => setOpen(false)}
  renderItem={(item) => {
    if (item.type === "image") {
      return <CustomImageViewer url={item.url} />
    }
    return null // Use null to render nothing for this item
  }}
/>

Keyboard navigation

Keyboard shortcuts are active when the lightbox is open.

KeyAction
← / →Navigate to previous / next item
EscClose the lightbox (configurable via closeOnEscape)

Zoom controls

Available for "image" items. Controls appear in the bottom-right corner of the content area.

ControlBehavior
Zoom in (+)Increases scale by 0.25x (max 5x)
Zoom out (−)Decreases scale by 0.25x (min 0.25x)
ResetReturns to 1x (only shown when zoomed)

When zoomed in, you can click and drag to pan around the image.

Download

The download button in the header triggers the following flow:

  1. Calls onDownload callback
  2. Attempts fetch with mode: "cors" to get the file as a Blob
  3. Creates a temporary download link via URL.createObjectURL
  4. Falls back to direct <a download> if the fetch fails

Disable the download button entirely with downloadable={false}.

Touch & swipe

Touch gestures work on mobile and touch-enabled devices.

A swipe is registered when:

  • Horizontal distance exceeds 50px
  • Horizontal distance is greater than vertical distance (avoids triggering on scroll)

Swipe right → previous item. Swipe left → next item.

Examples

Image gallery with zoom

import { useState } from "react"
import { BosLightbox } from "bos-lightbox"

const images = [
  { url: "demo-images/mountains.svg", type: "image", name: "Mountain landscape" },
  { url: "demo-images/abstract.svg",  type: "image", name: "Abstract art" },
  { url: "demo-images/city.svg",      type: "image", name: "City skyline" },
]

export default function Gallery() {
  const [open, setOpen] = useState(false)

  return (
    <>
      <button onClick={() => setOpen(true)}>
        View gallery
      </button>
      <BosLightbox
        items={images}
        open={open}
        loop
        onClose={() => setOpen(false)}
      />
    </>
  )
}

Mixed content (images + PDFs + video)

const items = [

]

<BosLightbox
  items={items}

  initialIndex={1}
  onClose={() => setOpen(false)}
/>

Imperative control with ref

import { useRef } from "react"
import { BosLightbox, type BosLightboxRef } from "bos-lightbox"

function ControlledPreview() {
  const ref = useRef<BosLightboxRef>(null)
  const [open, setOpen] = useState(false)

  return (
    <>
      <button onClick={() => ref.current?.openAt(0)}>
        Open first
      </button>
      <button onClick={() => {
        const idx = ref.current?.getCurrentIndex() ?? -1
        console.log("Current index:", idx)
      }}>
        Log index
      </button>
      <BosLightbox
        ref={ref}
        items={items}
        open={open}
        onClose={() => setOpen(false)}
      />
    </>
  )
}

<BosLightbox

  onClose={() => setOpen(false)}
