Roadmap

Planned features and improvements for bos-lightbox.

June 2026

In progress

Playwright E2E testsIn progress

Add browser-level E2E tests for dialog behavior, keyboard nav, and touch support across browsers.

  • •Unit tests for open/close, navigation, zoom, keyboard events
  • •Playwright tests for native dialog showModal/close
  • •Accessibility testing with axe-core

Planned

Storybook storiesPlanned

Build Storybook stories for every prop combination — modal, inline, images, PDFs, zoom, download, edge cases.

CSS custom properties for themingPlanned

Expose CSS variables for overlay background, backdrop blur, button colors, animation speeds.

Under research

React 19 compatibilityResearch

Test and certify compatibility with React 19. Evaluate useActionState for closer form integration.

Shipped

React component with native dialogShipped

Pure React implementation with forwardRef API, native <dialog> modal, zero runtime deps.

Image, PDF, video, fallback typesShipped

Four item types: image with zoom & drag-to-pan, PDF with iframe, video with controls, fallback with download.

Keyboard & touch navigationShipped

Arrow keys, swipe gestures, Escape, circular loop, slideshow auto-play.

Thumbnail stripShipped

Horizontal scrollable thumbnail strip at the bottom for visual navigation.

Animations & custom renderingShipped

Fade animations on open/close and item transitions. Custom renderItem prop. Inline mode close support.
