Roadmap

What is coming next for bos-lightbox — planned features, improvements, and long-term vision.

Last updated: June 2026

🔄 Now — In progress

🧪 Test suite & Playwright E2E In progress

Add comprehensive tests for the React component — unit tests with Vitest + jsdom and browser-level E2E tests with Playwright for dialog behavior, keyboard nav, and touch support.

  • •Component unit tests for controlled open/close, item navigation, zoom, keyboard events.
  • •Playwright tests for native dialog showModal/close behavior across browsers.
  • •Accessibility testing with axe-core integration.

⏳ Next — Planned

📖 Storybook stories & visual regressions Planned

Build Storybook stories for every prop combination — modal, inline, images, PDFs, zoom, download, dark overlay, edge cases.

  • •Stories for all display modes, item types, and navigation options.
  • •Chromatic visual regression testing to catch unintended style changes.
🎨 Theming via CSS custom properties Planned

Expose CSS custom properties for easy styling — overlay background, backdrop blur, button colors, animation speeds.

  • •Define and document all CSS variables for the component.
  • •Add a light/dark mode example to documentation.

🔭 Later — Under research

⚡ React 19 & concurrent features Research

Test and certify compatibility with React 19. Evaluate useActionState or other React 19 APIs for closer form integration.

✅ Shipped

📦 React component with native dialog Shipped

Pure React implementation with forwardRef API, native <dialog> modal mode, and zero runtime dependencies.

🖼️ Image/PDF/video support Shipped

Four item types: image with zoom & drag-to-pan, PDF with iframe, video with native controls, and fallback with download prompt.

⌨️ Keyboard & touch navigation Shipped

Arrow key navigation, swipe gestures, Escape to close, circular loop mode, and slideshow auto-play with configurable interval.

🖼️ Thumbnail strip for visual nav Shipped

Horizontal scrollable thumbnail strip at the bottom for quick visual navigation between items. Shows image previews or type icons.

🎭 Animations & custom rendering Shipped

Fade animations on open/close and item transitions. Custom renderItem prop for complete control over content rendering. Inline mode Escape & overlay close.
