Preview images, PDFs,

A component for viewing documents inside a modal or inline overlay. Keyboard navigation, zoom controls, touch gestures, and zero runtime dependencies beyond React.

Get started GitHub 
// Quick start
npm install bos-lightbox

import { BosLightbox } from "bos-lightbox"

function App() {
  const [open, setOpen] = useState(false)
  const items = [
    { url: "/photo.jpg", type: "image", name: "Photo" },
    { url: "/doc.pdf",   type: "pdf",    name: "Report" },
  ]

  return (
    <>
      <button onClick={() => setOpen(true)}>Open</button>
      <BosLightbox
        items={items}
        open={open}
        onClose={() => setOpen(false)}
      />
    </>
  )
}

What it does

A focused preview component for React projects

🖼️

Image preview

Full-resolution images with zoom and drag-to-pan. Loading spinner and fade-in included.

📄

PDF support

Renders PDFs in an iframe. Falls back to download on error.

⌨️

Keyboard nav

Arrow keys to browse. Escape to close. Native focus trapping with <dialog>.

📱

Touch support

Swipe to navigate on mobile. Threshold-based gesture detection.

🔍

Zoom controls

In, out, and reset. Range from 0.25× to 5×. Drag to pan when zoomed in.

⬇️

Download

Download button with CORS fetch fallback. Hide it with downloadable={false}.

🎯

Two modes

Modal uses native dialog. Inline renders as an overlay with dot indicators.

📦

Zero deps

Only requires React 16.8+. TypeScript types included. ESM + CJS builds.
