✨ v0.1.0 — React lightbox

Preview documents,
images & PDFs with zero friction

A lightweight, accessible React component for previewing images, PDFs, and documents. Keyboard navigation, zoom controls, touch/swipe gestures, and native <dialog> modal support.

Get started → View on GitHub 
// Quick start — install
npm install bos-lightbox

// Import and use
import { BosLightbox } from "bos-lightbox"

function App() {
  const [open, setOpen] = useState(false)
  const items = [
    { url: "https://picsum.photos/800/600", type: "image", name: "Sample.jpg" },
    { url: "/doc/sample.pdf",         type: "pdf",    name: "Report.pdf" },
  ]

  return (
    <>
      <button onClick={() => setOpen(true)}>Open lightbox</button>
      <BosLightbox
        items={items}
        open={open}
        onClose={() => setOpen(false)}
      />
    </>
  )
}

Everything you need

A complete preview experience with zero runtime dependencies

🖼️

Image preview

Full-resolution image preview with loading spinner, fade-in transition, and zoom controls (in/out/reset). Supports common formats.

📄

PDF support

Inline PDF rendering via browser-native iframe. Graceful fallback to download when PDF fails to load.

⌨️

Keyboard navigation

Arrow keys to navigate between items. Escape to close. Native <dialog> focus trapping built in.

📱

Touch & swipe

Touch/swipe gesture support for mobile devices. Smooth navigation between items with minimum swipe threshold.

🔍

Zoom controls

Zoom in/out with smooth CSS transitions. Reset to default view. Range from 0.25× to 5× magnification.

⬇️

Download support

One-click download with cross-origin blob fetch fallback. Configurable via the downloadable prop.

🎯

Two display modes

Modal mode uses native <dialog> with blur backdrop. Inline mode renders as a positioned overlay with dots indicator.

♿

Accessible

ARIA labels on all controls, keyboard-operable, proper focus management, and screen reader friendly.

📦

Zero runtime deps

Only peer dependency is React 16.8+. Tree-shakeable ESM + CJS builds. TypeScript types included.
